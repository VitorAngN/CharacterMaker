# CharacterMaker
Criador e gerenciador de fichas de D&D 2024. Monta o personagem passo a passo, calcula e explica cada número da ficha e mantém a ficha viva durante a campanha (PV, condições, inventário, subida de nível e histórico).
> Em desenvolvimento: fase 0 (estrutura do projeto).
## Stack
C# / .NET 10 · ASP.NET Core · Blazor WebAssembly · PostgreSQL
